What to record next

        
    
          
  1. Session and card on every call. Most sessions ran on main, so branch names link only 16 of 739 sessions to a card. lease start already logs the session id; write it into the run record and attribute cost by the claim-to-land window, not the whole session.
    2. 
          
  2. Actual cost per run. Roll each transcript's usage (input, 5-minute and 1-hour writes, reads, output, thinking, effort, peak context) into runs/<card> with the price version used, instead of the lib.mjs estimate.
    3. 
          
  3. Outcome with the cost. First pass, bounces, verifier verdict, your review minutes and reverts within 7 days, so cost per landed card includes the failed attempts.
    4. 
          
  4. Active versus waiting time. Split wall time into model time, tool time (cargo builds, tests) and idle gaps waiting on you, from transcript timestamps.
    5. 
          
  5. Size of the change. Lines and files changed and tests added per card, for cost per 100 changed lines and per test.
    6. 
          
  6. Subagent tree. Parent session, subagent type and model for each subagent file, so delegation pays for itself or not, per role.
    7. 
          
  7. Context resets and compaction. When a session crossed 200k, 400k and 700k, and whether it restarted.
