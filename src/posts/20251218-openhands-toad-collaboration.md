<p>Terminal-based AI coding assistants have grown rapidly in popularity. Tools like Claude Code, Gemini CLI, and OpenHands CLI give developers the ability to interact with AI agents directly in the terminal—the environment where many of us spend most of our working day.</p><p>But each tool comes with its own interface, its own quirks, and its own limitations. What if there was a universal interface that could work with any AI agent?</p><p>That&#x27;s the vision behind <a href="#">Toad</a>, a project by <a href="#">Will McGugan</a>, the creator of the popular Python libraries <a href="#">Rich</a> and <a href="#">Textual</a>. OpenHands is proud to be a sponsor of Toad&#x27;s development and one of its recommended agents.</p><h1>What is Toad?</h1><p>Toad is a universal terminal interface for AI agents. The name comes from &quot;<strong>t</strong>extual c<strong>ode</strong>&quot;—combining the Textual framework with coding assistance. Built on the Textual library, Toad provides a modern terminal user experience that goes beyond what traditional command-line tools offer.</p><p>Toad addresses several limitations common to existing terminal-based AI tools:</p><p><strong>No flickering or visual artifacts.</strong> Many terminal AI tools suffer from flickering as they update content. Toad can update partial regions of the screen—down to a single character—without redrawing everything.</p><p><strong>Scrollback that works.</strong> You can scroll back through your conversation history and interact with previous outputs, including copying text without garbled formatting.</p><p><strong>A unified experience.</strong> Instead of learning different interfaces for different AI agents, Toad provides a consistent experience across all supported agents through the <a href="#">Agent Client Protocol</a> (ACP).</p><h1>The Agent Client Protocol</h1><p>Toad uses the <a href="#">Agent Client Protocol</a> (ACP) to communicate with AI agents. ACP is a standardized protocol—similar in concept to the Language Server Protocol (LSP)—that allows editors and interfaces to communicate with any compatible AI agent. We previously wrote about <a href="#">how to use OpenHands in your favorite editor through ACP</a>.</p><p>With ACP support, Toad can act as a front-end for multiple agents. Users can switch between Claude Code, Gemini, OpenHands, and other compatible agents from within the same interface.</p><h1>OpenHands in Toad</h1><p>OpenHands is included as a recommended agent in Toad&#x27;s agent store. When users browse available agents in Toad, they&#x27;ll find OpenHands listed alongside other options, with easy installation and configuration.</p><p>The integration uses the OpenHands CLI&#x27;s ACP mode. After installing OpenHands, users can launch it directly from Toad&#x27;s interface:</p><ol role="list"><li>Open Toad&#x27;s agent store</li><li>Find OpenHands in the list of recommended agents</li><li>Click &quot;Install&quot; to set up OpenHands via <code>uv tool install openhands --python 3.12 &amp;&amp; openhands login</code></li><li>Select OpenHands and start a conversation</li></ol><p>Toad handles the ACP communication layer, so users get the same polished terminal experience whether they&#x27;re using OpenHands or any other supported agent.</p><h1>Why This Partnership?</h1><p>At OpenHands, we believe the future of software development should be open and community-driven. Will McGugan shares that commitment—Rich and Textual are both open source projects used by millions of developers.</p><p>Toad represents an important step toward making AI coding tools more accessible. Rather than being locked into a single vendor&#x27;s interface, developers can choose the agent that best fits their needs while enjoying a consistent, high-quality terminal experience.</p><p>By sponsoring Toad&#x27;s development, OpenHands is helping to build open infrastructure that benefits the entire developer community. And as a recommended agent in Toad, OpenHands becomes more accessible to developers who prefer terminal-based workflows.</p><h1>Get Started</h1><p>To try Toad with OpenHands, install it using <a href="#">uv</a>:</p><p><code><br/>uvx batrachian-toad<br/>‍<br/></code></p><p>For more installation options and documentation, visit <a href="#">batrachian.ai</a>.</p><p>From there, you can browse Toad&#x27;s agent store and install OpenHands with a single click. To learn more about OpenHands, visit our <a href="#">documentation</a>, try <a href="#">OpenHands Cloud</a>, or join our <a href="#">Slack community</a>.</p>
