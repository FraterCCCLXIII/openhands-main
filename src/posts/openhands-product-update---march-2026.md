We’re excited to announce new features in our latest OpenHands Cloud release that help you plan and scope your work, and discover Agent Skills more efficiently!

## Planning Mode BETA

The new Planning Agent lets you seamlessly switch between Plan Mode and Code Mode. In Plan Mode, you can provide high-level direction and the agent will generate a structured PLAN.md file outlining the steps needed to implement your feature. For vague or unclear prompts, the agent will also ask questions to help elicit requirements for the plan. The generated plan is saved within the workspace, making it readily available for implementation using Code Mode.

![](/assets/webflow/blog/openhands-product-update---march-2026/46932303.png)

## GUI Slash Menu

The GUI Slash Menu makes it easier to access Agent Skills loaded in your current conversation context. Simply type a / in the GUI to see a list of loaded Agent Skills and quickly select what you need. Future enhancements will include native slash commands for workflows like loading plugins and extending functionality.
