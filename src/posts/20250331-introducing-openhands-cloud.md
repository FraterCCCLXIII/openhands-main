Today, we're thrilled to announce the full release of OpenHands Cloud, our hosted platform that brings the power of state-of-the-art AI software development to your browser at [app.all-hands.dev](https://app.all-hands.dev)!

## State-of-the-Art Agents

OpenHands Cloud brings the same powerful capabilities as our local version, which has proven itself as the strongest AI software development agent in the world. Our agents can handle a wide variety of development tasks, including bug fixes, feature implementations, and regular maintenance. OpenHands is particularly good at taking toil off your plate--fixing tests, resolving merge conflicts, and addressing nitpicky PR comments.

## Seamless GitHub Integration

One of the most powerful features of OpenHands Cloud is its deep integration with GitHub. You can:

- Start an OpenHands session directly from GitHub issues by adding the `openhands` label or mentioning `@openhands`
- Mention `@openhands` in pull request comments to get instant assistance
- Seamlessly transition from GitHub discussions to interactive sessions with full repository context
- Have OpenHands create and update pull requests automatically

![GitHub Integration](/assets/blog/20250331-introducing-openhands-cloud/github-integration.png)

The integration maintains all the context of your codebase and development workflow, making it feel like a natural extension of your existing tools rather than a separate system.

## Different Ways to Interact

We believe AI assistants should adapt to your workflow, not the other way around. That's why OpenHands Cloud supports multiple ways to interact:

- Traditional text chat through your browser
- Mobile interface for on-the-go development assistance
- Integration with your favorite development tools

No matter where you are or how you prefer to work, OpenHands is there to help.

## Parallel Agent Capabilities

One powerful feature of the OpenHands Cloud is its ability to run multiple agents simultaneously. This means you can:

- Have different agents working on different parts of your codebase
- Maintain separate conversations for different projects or features
- Scale your development efforts by parallelizing AI assistance

![Multiple agents working simultaneously](/assets/blog/20250331-introducing-openhands-cloud/multi-conversation.png)

This parallel processing capability significantly increases your productivity by allowing you to tackle multiple tasks simultaneously.

## Open Source Foundation

While OpenHands Cloud provides a convenient hosted solution, we remain committed to open source. The underlying [OpenHands codebase](https://github.com/OpenHands/OpenHands) is fully open source, allowing you to:

- Understand exactly how the system works
- Contribute new features or improvements
- Customize the agent's behavior for your specific needs
- Run OpenHands on your laptop

We believe in transparency and community collaboration, and we're excited to see how developers will extend and enhance OpenHands' capabilities.

## Getting Started

Getting started with OpenHands Cloud is simple:

1. Visit [app.all-hands.dev](https://app.all-hands.dev)
2. Connect your GitHub account
3. Select the repositories you want to work with
4. Start collaborating with your AI development partner!

We can't wait to see what you'll build with OpenHands Cloud. Whether you're a solo developer, part of a team, or managing multiple projects, OpenHands is ready to amplify your development capabilities.

Join us in shaping the future of software development!
