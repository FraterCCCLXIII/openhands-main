<p>Coding agents like <a href="https://openhands.dev">OpenHands</a> can automate many software development tasks. However, running them typically requires expensive cloud APIs or dedicated data center infrastructure, raising concerns about cost and privacy. An alternative is to run coding agents directly on your workstation. With advances in open-weight models and edge AI processing, smaller locally-runnable models are now achieving competitive results—approaching their larger counterparts on benchmarks like <a href="https://www.swebench.com/">SWE-Bench Verified</a>—making self-hosted coding agents a viable option.</p><h2>The AMD Stack for Language Model Serving</h2><p>The <a href="https://www.amd.com/en/products/processors/laptop/ryzen/ai-300-series/amd-ryzen-ai-max-plus-395.html">AMD Ryzen™ AI Max+ 395 processor</a> combines 16 Zen 5 CPU cores with a Radeon™ 8060S integrated GPU and an XDNA 2 Neural Processing Unit (NPU). Together, these components deliver up to 126 AI TOPS (Tera Operations Per Second), providing the compute needed to run language models locally. The processor includes 64 MB of L3 cache and supports high-bandwidth LPDDR5X memory, enabling inference with models like <a href="https://huggingface.co/Qwen/Qwen2.5-Coder-32B-Instruct">Qwen3-Coder-30B</a>.</p><p>To utilize this hardware, AMD has developed <a href="https://github.com/lemonade-sdk/lemonade">Lemonade Server</a>, a software stack that enables local large language models to run with NPU and GPU acceleration. Lemonade supports the OpenAI API standard, making it compatible with existing AI applications and tools. Lemonade provides accelerated and efficient coding agent execution by leveraging the integrated NPU, GPU, and CPU on the Ryzen AI™. The server works across platforms and supports popular inference engines, including optimized backends for AMD hardware.</p><p>By combining the Ryzen AI Max+ 395&#x27;s hardware with Lemonade&#x27;s software stack, developers can run models like Qwen3-Coder-30B locally while maintaining reasonable performance. This approach enables private, cost-effective AI development for those who prefer to keep their code on-premises.</p><h2>Setting Up AMD Ryzen AI with Lemonade</h2><p>AMD and OpenHands are collaborating to make it easier to run coding agents locally on AMD hardware. Here&#x27;s how to get started:</p><h3>Prerequisites</h3><p>Before starting, ensure you have:</p><p>• A compatible Linux or Windows environment<br/>• Administrative access to install required software</p><h3>Step 1: Install Lemonade Prerequisites</h3><p>For detailed installation instructions, see the <a href="https://lemonade-server.ai/">Lemonade Getting Started guide</a>. On Windows, Lemonade works out of the box. On Linux, ensure that the <a href="https://www.amd.com/en/products/software/rocm.html">ROCm</a> tools are installed before proceeding.</p><h3>Step 2: Install Lemonade</h3><p>Lemonade is AMD&#x27;s optimized software stack for running large language models on AMD hardware. To install and run Lemonade, first <a href="https://lemonade-server.ai/">download and install Lemonade</a> then run</p><p><code><br/>lemonade-server serve --host 0.0.0.0 --ctx-size 32768<br/>‍<br/></code></p><p>When you start the Lemonade server, you&#x27;ll see output like this:</p><p><code><br/>🍋 Open http://0.0.0.0:8000 in your browser for:<br/>🍋 💬 chat<br/>🍋 💻 model management<br/>🍋 📄 docs<br/>‍<br/></code></p><p>The Lemonade server will automatically download the Qwen3-Coder-30B-A3B-Instruct model (approximately 18.6GB) on first run.</p><h3>Step 3: Install OpenHands</h3><p>There are many ways to use OpenHands through the CLI, GUI, and SDK and for detailed instructions you can see the <a href="https://docs.openhands.dev/openhands/usage/run-openhands/cli-mode">OpenHands documentation</a>. Here, we&#x27;ll use the CLI, which is easy to install and start using through <a href="https://docs.astral.sh/uv/getting-started/installation/">uv</a>:</p><p><code><br/>uvx tool install openhands<br/>‍<br/></code></p><p>This will start the OpenHands interactive command-line interface.</p><h3>Step 4: Configure OpenHands to Use Lemonade</h3><p>To connect OpenHands to your local Lemonade server, you&#x27;ll need to configure the LLM settings. In the OpenHands CLI:</p><p><strong>1.</strong> Type <code>/settings</code> and press Enter to access the configuration menu</p><p><strong>2.</strong> Select <strong>&quot;LLM (Basic)&quot;</strong> to configure a custom LLM endpoint</p><p><strong>3.</strong> When prompted, enter the following configuration:</p><p><strong>Provider: </strong>lemonade</p><p><strong>Model:</strong> <code>Qwen3-Coder-30B-A3B-Instruct-GGUF</code></p><p><strong>4.</strong> Confirm to save the settings</p><p>Your OpenHands CLI is now configured to use your local Lemonade server! The settings are persisted for all future sessions.</p><h3>Step 5: Start Your First Conversation</h3><p>Back at the main CLI menu, start a new conversation by typing your request. For example:</p><p>&quot;Create a website that showcases Ryzen AI and the ability to run the OpenHands coding agents locally through the Lemonade software stack. Make the website fun with a theme of lemonade and laptops.&quot;</p><p>The OpenHands agent will begin working on your task using the local Qwen model running on your AMD hardware. You&#x27;ll see the agent writing code, testing, and iterating until everything is complete.</p><p>Once the agent completes its work, you can view and interact with the generated code in the working directory.</p><h2>Why Self-Host with AMD and OpenHands?</h2><p>When using coding agents, many developers rely on powerful but closed API-based models like Claude and GPT. While these models are effective, there are compelling reasons to use open-weight models and host them yourself:</p><p><strong>1. Privacy:</strong> Your code and intellectual property never leave your machine</p><p><strong>2. Cost:</strong> No per-token API costs, especially beneficial for long-running tasks</p><p><strong>3. Compliance:</strong> Meet regulatory requirements for government, healthcare, and finance</p><p><strong>4. Performance:</strong> Low latency with local inference</p><p><strong>5. Flexibility:</strong> Full control over model selection and configuration</p><p><strong>6. Offline Capability:</strong> Work without internet connectivity</p><h2>Conclusion</h2><p>Going forward, at OpenHands we&#x27;re working on developing additional local model capabilities and methods for you to adapt models on your own data using AMD Ryzen AI.</p><p>We hope that this post has been useful, and if you&#x27;d like to try setting things up yourself, please join our <a href="https://all-hands.dev/joinslack">Slack community</a> or check out our <a href="https://docs.all-hands.dev/">documentation</a> for more information. And thanks to AMD for the collaboration on this integration!</p>
