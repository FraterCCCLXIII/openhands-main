We rely on the OSS ecosystem—and we want to give back *where it moves the needle most*: active maintainers of **established (mid‑size and up) open‑source projects** who spend real time on upkeep.

**Get &#36;100 to &#36;500 in [OpenHands Cloud](https://app.all-hands.dev) credits** to offload routine maintenance tasks, bug fixes, or features to an AI coding agent you control.

## Who's Eligible?

We're focusing this program on maintainers of **established (mid‑sized+) public GitHub repos**—projects big enough that maintenance is real work.

You qualify if the followings are true (checked over the *last 90 days* unless noted):

* You have **maintainer / write access** on the repo **and** the repo has **≥100 GitHub stars**.  
* The repo shows **≥20 merged PRs total** (all contributors) in the last 90 days *and* at least **2 distinct external contributors**.  
* You personally authored **≥5 merged PRs** across the repo/org in the last 90 days.  
* Edge case? Tell us. (Infra sub‑repos, split monorepos, etc.—we'll review manually.)

Multiple repos? List them all; we aggregate activity.

**How much credit do you get?** We size grants during review (typically in the &#36;100 to &#36;500 range) based on repo activity and maintainer needs. Credits can be refilled (see below).

## Refill Credits (Show Use, Get More)

You can re‑apply for additional credits once you've *actually used* OpenHands Cloud to land maintenance work.

We'll auto‑check for OpenHands‑assisted pull requests under your GitHub handle. Rough guide over the last 60 days:

* **Refill OK** when we see **≥5 merged OpenHands PRs** touching the repo *and* usage on **≥4 separate days**.  
* Higher‑volume projects (or multiple repos) that show **≥10 merged OpenHands PRs** may unlock larger refills.

Refill amounts typically land between **&#36;100 to &#36;300**, scaled by usage; high‑impact maintenance streaks may receive more.

## How to Apply (Takes ~2 min)

1. Open the form and drop your **GitHub handle(s)** and **repo link(s)**.  
2. Briefly describe your **maintenance pain points** (what's slowing you down?).  
3. (Optional) Paste links to recent PRs/issues that show activity.  
4. Submit! We review **weekly** and email decisions within ~7 days.

## What Counts as an "OpenHands PR"?

Any PR where OpenHands generated meaningful code / docs / config that you reviewed and merged. **Signals we look for**: PRs where the first commit is authored by openhands (standard on [LogicStar Insights](https://insights.logicstar.ai/)).

## Quick FAQ

**Private repos?** This program targets public OSS; contact us for nonprofit/security cases.

**Team applications?** Yes—note your teammates; we may pool credits for a shared project.

**Corporate sponsorship?** We're happy to match! Email open-source-credits@all-hands.dev.
