Agent Canvas is the new face of OpenHands: a local, visual workspace for running AI coding agents.

You can install it on your laptop, connect the agents you already use, and start running real engineering work without Docker or complex setup. It is designed for the way developers already work today, while giving teams a path from one local session to an always-on agent system.

## One workspace. All your agents.

Most coding-agent tools stop at one session. That ceiling shows up quickly: agents run one task at a time, stop when your laptop closes, and cannot turn repeated work into a workflow.

Agent Canvas adds the missing layer around those agents:

- Run multiple agent sessions in parallel, each on its own branch.
- Connect Claude Code, Codex, Gemini CLI, and the OpenHands harness through the open Agent Client Protocol.
- Switch between local, VM, and cloud backends without changing interfaces.
- Build automations that run on a schedule or trigger from engineering events.
- Share automations, skills, and plugins across your team.

## Built for automations

Agent Canvas includes an automations engine so you can stop doing the outer loop by hand. Create a Monday morning dependency update, trigger a code review when a pull request opens, or let an agent respond to events from GitHub, Slack, Jira, PagerDuty, and CI.

Define the workflow once, then let your agents keep working.

## Start local. Scale when ready.

Individual developers can start locally for free. Teams can add cloud execution, integrations, and shared workflows. Enterprises can scale to governed agent fleets with SSO, RBAC, audit logs, budget controls, sandboxed execution, and self-hosted infrastructure.

Download Agent Canvas from [GitHub Releases](https://github.com/OpenHands/OpenHands/releases), then use the [connection guide](https://docs.openhands.dev/openhands/usage/run-openhands/acp) to connect your first ACP-compatible agent.
